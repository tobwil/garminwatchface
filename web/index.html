Auf die Uhr

Face-Code
Code einfügen

  1. ZIP entpacken. Darin liegt eine .prg-Datei – das ist dein fertiges Watchface.
  2. Uhr per USB anschließen. Am Mac brauchst du dafür OpenMTP oder Android File Transfer.
  3. Datei nach GARMIN/APPS kopieren und die Uhr trennen.
  4. Aktivieren: Auf der Uhr Watchface lange drücken → Watchface wählen → durchblättern. Gleicher Name ersetzt das vorhandene Watchface, ein neuer Name legt ein zusätzliches an.

Variante, Akzentfarbe und Datenfelder kannst du später auch direkt an der Uhr im Watchface-Editor ändern. FTP, Gewicht und Ziele stehen im Menü Einstellungen des Watchfaces.
